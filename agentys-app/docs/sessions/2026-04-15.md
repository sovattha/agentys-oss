# Session du 2026-04-15

## Branche : `main`

### Changements
- Corrige 4 bugs dans le pipeline d'onboarding qui rendaient profil, contacts, style et savoir quasi vides ou contaminés
- Isoler le KnowledgeAgent aux emails SENT (bodies RECV masqués) pour empêcher l'hallucination de terminologie tierce
- Indexer compte maintenant sent + recv pour les contacts, avec filtre noreply/newsletter et ranking bidirectionnel
- ProfileAgent voit le body complet (1800 chars) et préfère les emails longs pour extraire la signature
- StyleAgent trie par longueur de body (initiateurs first) au lieu des 5 premiers arbitraires
- Loader default 250 emails (split 60/40 sent/inbox), frontend envoie max_emails: 250
- 4 tests de non-régression ajoutés (noise filter, bidirectional ranking, recv-only contacts, RECV body isolation)
- Fix test obsolète sur `projects` (déjà cassé sur main, clé droppée par _FORBIDDEN_KEYS)

### Découvertes
- Le modèle DB Email n'a pas de champ `signature` — seul Account en a un. Le ProfileAgent doit extraire depuis le body.
- RepositoryLoader chargeait 2x le limit (inbox + sent séparément, chacun jusqu'à 5000) sans plafonner le total
- L'indexer excluait 100% des emails reçus du calcul contacts, ce qui vidait la liste pour les utilisateurs à faible volume d'envoi

### Décisions
- Body preview 200 -> 1800 chars (pas illimité) pour garder la taille du prompt LLM raisonnable tout en capturant les signatures
- Split 60/40 sent/inbox plutôt que 50/50 : le SENT est plus précieux pour ProfileAgent et StyleAgent
- Pas de changement frontend dans Step3TrainAI (le rendu conditionnel est correct, c'était le backend qui ne fournissait pas les données)

## Session 5 — Fix 4 bugs UI + 2 tests pré-existants + refactor onboarding terminology→faq

### Changements
- **Deep Focus freeze** : le bouton éclair forçait un fetch de 500 emails sans cache, gelant le renderer. Utilise maintenant les emails cachés (instantané)
- **Send button** : `sendingRef` jamais reset après envoi réussi, bloquant les envois suivants si le composant est réutilisé. Reset aussi dans le flow "Send Anyway" (attachment reminder)
- **Renderer freezes streaming** : draft chunks (100-200ms) déclenchaient des setState à chaque event. Throttle via RAF (1 notification/frame max). Labels updates wrappés dans `startTransition`
- **Autocomplete contacts** : adresses email non enregistrées n'apparaissaient pas en suggestion. Ajout d'une suggestion synthétique quand la query est un email valide
- **Tests pré-existants** : oauth redirect_uri attendait `127.0.0.1:5050` alors que le mode dev utilise un proxy Vite (URL relative). `__APP_VERSION__` non défini en vitest, guard ajouté
- **Onboarding** : refactor terminology→faq dans schemas, agents, PillarSavoirReadOnly simplifié

### Décisions
- Revert `queueMicrotask` dans websocket handlers : ne yield pas au renderer (microtasks = même frame) et casse les tests synchrones. RAF est le bon outil pour le throttling UI
