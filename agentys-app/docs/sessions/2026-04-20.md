# Session du 2026-04-20

## Branche : `main`

### Changements
- `QuickEventPopover` : le chip « Étiquette » s'affiche désormais même quand l'utilisateur n'a aucun label projet. Le dropdown propose alors un mini-formulaire inline (input + bouton Créer) qui crée le label via `createLabel({ is_project: true })` avec une couleur par défaut, puis le sélectionne automatiquement.

### Décisions
- Création inline dans le dropdown plutôt que navigation vers le `LabelEditor` : garde l'utilisateur dans le flow de création d'événement, une seule interaction.
- Palette par défaut cyclique de 6 couleurs — évite d'imposer un picker à ce stade, l'utilisateur peut ajuster plus tard depuis le gestionnaire de labels.
