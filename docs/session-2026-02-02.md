### 4. Problèmes rencontrés et solutions

#### Problème 1: Frontend "Déconnecté"

**Symptôme**: Le frontend affiche "Assistant IA non disponible" et "Déconnecté"

**Cause racine**: Lancement de `run_daemon.py` au lieu de `run_api.py`

- `run_daemon.py` = daemon de polling email (pas de serveur HTTP)
- `run_api.py` = serveur API Flask + WebSocket

**Solution**: Lancer `python run_api.py --port 5050`

#### Problème 2: Erreur "no such table: accounts"

**Symptôme**:
```
sqlalchemy.exc.OperationalError: no such table: accounts
```

**Cause**: Base de données SQLite non initialisée

**Solution**:
```python
from app.db.database import init_db
init_db()
```

#### Problème 3: Erreurs CORS

**Symptôme**:
```
Access to fetch at 'http://localhost:5050/api/health' from origin
'http://localhost:1420' has been blocked by CORS policy
```

**Cause racine**: Flask-SocketIO utilise son propre serveur HTTP qui contourne les middlewares Flask-CORS

**Solution**: Modifier `app/api/app.py`

```python
# Avant
CORS(app, origins=cors_origins, supports_credentials=True)

# Après
CORS(app, resources={r"/*": {"origins": "*", "supports_credentials": True}})
```

Plus ajout de handlers `after_request` et `before_request` pour les headers CORS.
